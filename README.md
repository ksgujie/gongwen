# 党政机关公文自动排版引擎

基于 GB/T 9704-2012 的 Word/WPS 公文自动排版工具，使用 AutoHotkey v2 编写。

## 版本管理约定

- 每个版本保存为独立的 `.ahk` 文件，文件名即版本号，例如 `6.7.7.ahk`。
- 版本修改日志写在源码文件头部的「修改记录」中。
- 使用 Git 管理版本历史（Git 安装路径：`W:\git`）。
- 设置保存在注册表 `HKEY_CURRENT_USER\Software\DocFormatTool`，不再使用 `config.ini`。
- 日志、备份、Office 文档、PDF 和编译产物不纳入版本库。

## 运行

使用 AutoHotkey v2 运行对应版本的 `.ahk` 文件。静默处理模式支持将 Word 文件或文件夹作为参数传入。

## 设置迁移

通过主菜单「设置 → 导出当前所有设置 (注册表 .reg)」导出注册表文件，默认保存到程序所在目录（编译后为 EXE 目录，未编译为脚本目录），文件名为 `公文排版设置.reg`。换电脑后双击该 `.reg` 文件导入，再重新启动程序即可恢复全部设置（含整体配置方案、字体字号和当前方案）。
